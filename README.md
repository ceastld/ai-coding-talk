# 设计 Agent Loop

分享用的一页站。打开就能投屏。讲怎么设计写代码的循环，不讲模型，不堆 skill。

**现场：[https://ceastld.github.io/ai-coding-talk/](https://ceastld.github.io/ai-coding-talk/)**

- `F` 全屏 · 方向键 / 空格 翻页 · `P` 备注
- 地址带页码，例如 `#/4` 直接进内环图
- 源材料在 `talk/`：讲稿、走环脚本
- 仓库里没有密钥。公开只是为了 GitHub Pages

核心就两个环：

- **内环** Plan → Implement → Check ↺ → Accept（写入仓库）
- **外环** Issue → 内环 → PR → 人合
