# 示例动作 A：选中文字 → 扔给分拣

给人看「入口是动作，做法是 skill」。不是可导入的 Quicker 二进制，现场按这个结构讲或事后做成真动作。

## 人怎么用

1. 在邮件 / 论坛 / 聊天里选中一段反馈
2. 热键（例如 `Ctrl+Alt+I`）
3. 几秒后剪贴板里是：建议标签 + 一句人话 + 已处理/未处理点名

默认 **不改** 任何线上 issue。要写入 tracker，先把迷你 automation 的开关拨到 `apply-skills`，并且人点头。

## 步骤（讲解用）

1. 取当前选中文本。没有选中就取剪贴板。空的就提示「先选中反馈」。
2. 调用 Agent，只给这段文本，并要求遵守 `examples/mini-automation`：
   - 先点名已处理 / 未处理
   - 未处理再分拣
   - 缺信息用三问
   - 不要开修
3. 把 Agent 的人话结果写入剪贴板，并弹出一句短通知。

## 为什么这算 AI 编程

人负责 **何时按按钮**。
规则负责 **按了之后走哪条路**。
聊天窗口不再是唯一入口。
