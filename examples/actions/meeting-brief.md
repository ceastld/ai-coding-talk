# 示例动作 B：会前一页纸

分享前自己用，也适合当场说「Skill 不一定修 bug，也可以产讲解稿」。

## 人怎么用

热键或面板按钮「会前简报」。输出一页 Markdown，能直接念。

## 步骤（讲解用）

1. 读 `examples/skills/meeting-brief/SKILL.md`
2. 读 `talk/slides.md` 的标题列表（或当前仓库里要讲的材料）
3. 生成一页：
   - 今天只讲一句什么
   - 三条演示会碰到什么
   - 可能被问的两个问题 + 短答
4. 写到剪贴板，必要时落盘 ` /tmp/meeting-brief.md`

## 和动作 A 的差别

| | 动作 A | 动作 B |
| --- | --- | --- |
| 输入 | 别人的一段话 | 自己的讲稿仓库 |
| Skill | inbox-triage | meeting-brief |
| 风险 | 可能碰到真用户 | 只写给自己 |
| 自动程度 | 建议停在剪贴板 | 可以直接落盘 |

先让观众看 B，再看 A。B 没有「写进别人仓库」的心理负担。
