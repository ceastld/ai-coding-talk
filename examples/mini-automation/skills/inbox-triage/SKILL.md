# 进门分拣

## 何时用

- 新开的反馈
- 开着但没有类型标签

## 步骤

1. 先点名 **已处理** 或 **未处理**。已处理走 `already-done`。
2. 读标题、正文、已有标签。缺关键信息走 `need-more-info`。
3. 只打一个类型：坏了 → `bug`；想要新能力 → `enhancement`；问怎么用 → `question`。
4. 看不清就不要猜模块标签。
5. 分拣通常只改标签。开修不是这一步的事。

## 不要

- 不要关产品向的单
- 不要自己打 TryAutoFix
- 不要写长评论
