# 决策规则（演示）

能自动的别等人。不该自动的别自作主张。

## 执行开关

`mode: notify-only`

- `notify-only`：只告诉分享者会做什么，不改任何线上单。
- `apply-skills`：按表动手（演示结束前不要拨到这一档，除非你真的接了 tracker）。

## 动手之前

按顺序，中了就走，不再往下分析。

1. **处没处理。** 时间线、关联 PR、当前主线都看。已经没了 → `already-done`。还在 → 往下。
2. **是不是缺信息。** 没版本、没复现、没期望 → `need-more-info`。
3. **能不能看清类型。** 能 → `inbox-triage` 打一个类型标签。
4. **没有 TryAutoFix 或人点头，不开修。**

## 自动做（mode=apply-skills）

| 情况 | 动作 | skill |
| --- | --- | --- |
| 新反馈能看清是 bug / 需求 / 问题 | 打一个类型标签 | inbox-triage |
| 缺复现 / 版本 / 期望 | 三问，打「需要更多信息」 | need-more-info |
| 当前主线已经没了 | 关单，短说当前已经是这样 | already-done |

## 必须停

- 要不要做这个需求
- 标 wontfix 并关闭
- 承诺下周一定修好
- 只为这一个关键词打补丁
