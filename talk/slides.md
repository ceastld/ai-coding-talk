# AI 编程怎么真正跑起来

规则写进仓库。
Agent 按文件干活。

聊天窗口只办这一次。

---

# 同一条规则，你已经讲了第三遍。

它还是只活在聊天记录里。

这不是模型不够强。是制度没有落盘。

---

# 今天不评模型，不教 prompt。

1. **事情怎么进门** — 新反馈、开着的单、选中的一段话
2. **谁做，做到哪必须停** — 能自动的别问。不该自动的别做
3. **怎样算做完** — 已处理就关。不要请人再验证

---

# 聊天当流程，撑不久

**换窗口等于换制度**
同一个 bug 开三个会话，边界重讲三遍。第三遍已经和第一遍不一样。

**没写下来的禁令等于没有**
「这个别自动关」只存在于某次对话。下次 Agent 照关。

**做完的单关不掉**
「请再验证」把用户变成测试员。队列只增不减。

---

# 能连续跑的，是一张决策表

进门 → 处没处理 → 缺不缺信息 → 能不能看清 → 有没有钥匙

Agent 先读仓库里的规则，再读匹配的 skill，再动手。
改文件，行为跟着变。

---

# 第一句只问一件事

**已处理，还是未处理。**

看时间线、关联 PR、维护者备注、当前主线。不要只看用户正文。

只看正文，会把已经上线的单重新实现一遍。
证据够了就关。用户不是回归测试。

---

# 一种情况，一种做法

```
---
name: inbox-triage
description: 新反馈还没分类时：先点名已处理 / 未处理，再打标。
---
1. 先点名已处理或未处理
2. 缺信息就去三问
3. 只打一个类型标签
4. 开修不是这一步的事
```

description 是路由。写清何时用、自动做什么、何时停。
写意图，不要写下个月就会过期的工具参数。

---

# 动手必须有开关

```
mode: notify-only     # 只报，不动
mode: apply-skills    # 按表真正动手
```

「今天小心点」不是开关。
监控可以一直跑。写入 tracker 必须显式拨档。

---

# 能自动的别问。不该自动的别做。

**自动（不必问）**
- 能看清的 bug / 需求 / 问题 → 打一个类型标签
- 缺版本、复现、期望 → 固定三问
- 主线已经没了 → 关单
- 带了开修钥匙，且改法局部 → 才开修

**必须停**
- 要不要做这个需求
- wontfix、对外承诺版本号
- 改数据格式、动密钥、花钱
- 只为这一个关键词打补丁

开修的钥匙在标签和规则表里，不在聊天的语气里。

---

# 升级也要带球

1. 已经做了什么（先点名已处理还是未处理）
2. 建议怎么走：修 / 不修 / 等复现
3. 反对时回哪一个词：「不修」「等下版」

禁止只写：「先不改，等你定。」
那是把判断踢回去，不是升级。

---

# 三张假工单，当场走这张表

- **单 A** 截图贴图卡死 — 相关 PR 已合，当前已经没了
- **单 B** 动作运行很慢 — 没版本、没复现、没期望
- **单 C** 面板搜索清空丢选中 — 步骤清楚，没有开修钥匙

---

# 单 A：先看时间线，再开口

> 截图贴图会把窗口卡死。2.x 里贴图之后鼠标动不了。
> 相关开发 PR 已合进主线。当前已经没了。

1. 查时间线，不查情绪
2. 第一句点名：**已处理**
3. 关单。评论：当前已经是这样了。不要「请再验证」

---

# 单 B：看不清就先问

> 动作运行很慢。有时候会卡一下。没版本、没复现、没期望。

1. 点名：**未处理**
2. 看不清类型 → `need-more-info`
3. 三问：版本、怎么复现、你期望怎样。不要猜补丁

---

# 单 C：能看清也不等于开修

> 打开面板 → 搜「截图」→ 清空搜索框，原来高亮的项没了。当前预览。
> 没有 TryAutoFix，也没有人点头。

1. 点名：**未处理**
2. `inbox-triage` 打 `bug`，写一句摘要
3. 停。开修的钥匙在标签和规则表里，不在「我看懂了」里

---

# 自动的越多，这三道越要硬

1. **合并** — Agent 可以开 PR。合是人按的
2. **对外口径** — 不承诺版本号，不把源码贴进用户评论
3. **产品取舍** — 默认值、互斥、否过的方向，只升级，不让 Agent 拍板

---

# 自动层越能干，拒绝越要干净

**审查绿了 ≠ 能合**
自动审查对照旧文档，把当时合法的 CI 字段打成错误；同系列里也抓到过真的数据丢失。
瞥一眼，核合同，人决定。审查当参谋，不当闸。

**看起来像信封就拒绝**
`write_file` 的 payload 以 `@@` 开头但头是坏的。当原文写，目标文件被覆盖。
不要更聪明地猜。拒收，清半成品，用测试锁住「坏信封不得改磁盘」。

---

# 这周就能做的三件事

1. 把讲过两遍的做法写成 Skill。一种情况一个目录。写清何时停。
2. 仓库里加一行开关：只报 / 动手。不要靠「今天小心点」。
3. 关单标准写成：已处理就关。不要请人再验证。

本仓可以当场翻：`examples/mini-automation`

---

# 你们现在哪一层，还停在聊天记录里？

**停在聊天里怎么办？**
把重复的做法写成 Skill，把能不能动手写成仓库里的一行。下次不要翻旧聊天。

**能不能全自动合？**
不能。Agent 开 PR。合并、对外口径、破坏数据格式，还是人按。
