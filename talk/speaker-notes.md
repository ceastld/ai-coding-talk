# 讲解词

对着 slides 讲。括号里是可以省略的旁白。每节约 1–2 分钟。

## 开场

「今天不比模型。我想讲我们怎么让 AI 写代码这件事，能连续跑、能复查、能关掉。」

「如果只是开一个聊天窗口说『帮我修这个』，做三次还行。做三十次，规则会丢，边界会漂，单会永远停在请再验证。」

## 四层

用手比四层，从下往上或从上往下都行。强调：往下走一层，人就少说一遍。

对话层用我们自己的习惯举例：一条 PR 一个会话；漂了就新开，第一条带 PR 号。

交给 Agent 时：说现象和成功标准，不要指定第几行。合是人按的。

## Skill

打开 `examples/mini-automation/skills/inbox-triage/SKILL.md` 投屏。

念 frontmatter 的 description：「这句话是路由，Agent 靠它决定开不开这个文件。」

然后指步骤里的第一句：已处理还是未处理。说这是我们付过学费的。

## Automation

打开 `examples/mini-automation/policies/decision-rules.md` 的执行开关。

「改这一行就能从只报到动手。不用再跟 Agent 解释今天能不能改 issue。」

讲自动表和必须停的表。停的那些是人还要在的理由。

升级三条：做了什么、建议怎么走、反对回哪个词。可以举：「不修」「等下版」。

## 产品也是 Agent

一句话带过 MCP：本机端口，Bearer，eval 和动作进出。默认关。写要开门，删表也拦。

「所以 AI 编程不只是 IDE 里的事。产品自己也可以被别的 Agent 调用。」

## 演示

跟 `demo-script.md` 走。不要现场编规则。假反馈已经写在演示脚本里。

两个动作讲「人是入口」：热键 / 选中文字，后面接的是 skill，不是又一个空白聊天。

## 真事（各 1 分钟）

审查：合法的 CI 字段被旧文档判非法；同时真的数据丢失也被抓到。所以瞥一眼，不当闸。

写文件：坏的 `@@` 头不能当正文。看起来像协议就拒绝。

测试：Agent 相关契约要能在 Linux 跑，否则只有 Windows 能证明它没坏。

## 收尾

念三句带走。停下来问：「你们现在哪一层还停在聊天记录里？」
